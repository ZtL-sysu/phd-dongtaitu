# Implementation ownership and common interfaces

Planned at P1B; code/setup begins after pre-experiment review acceptance. Package root `edsgn/`, imports from its `src/edsgn/`. One writer per assigned file. Python execution only in selected local Conda environment.

## Data owner interface

`data.py`: PreparedData loads an npz of raw observable values, separate targets/input_mask/target_mask,interval_end,node_ids,events (time-bin,src-node,dst-node or MOOC-user/activity). Normalization uses training-only log1p means/std for counts, ordinary training-only mean/std for signed synthetic. Robust residual scales from raw training observations, count lower bound1. `load_dataset(path)` exposes .values/.targets/.input_mask/.target_mask/.obs_age/.interval_end/.node_ids/.splits/.mean/.std/.scale/.count_data/.horizons/.history/.hmax/.events. Split windows `origins(split)` enforce every future target in that split; .window(origin,mask_override=None) returns normalized values,raw observations,mask,obs_age and within-window causal event records. Targets are fetched separately. Multi-trajectory synthetic files are separate PreparedData objects and share train-fit statistics; validation/test generators use new trajectory seeds. Oracle P/switch metadata remains separate evaluation-only files and never enters `window`.

`prepare.py`: `--dataset synthetic|email|mooc --config ... --output ...`; downloads raw official files at P2 with source/date/sha256/size record, preserves repeated email triples, exact checks on repeated MOOC ACTIONID, no dropout file load. Count bins are half-open and last possible partial excluded. Nodes determined by training events before constructing core arrays; record later excluded nodes/events. No fabricated calendar covariates. MOOC activity-only forecasting, optional within-window shared-user prior capped toK candidates/row with explicit conversion-work counts.

## Core model interface

`ModelConfig`: n_nodes,n_features,history,hmax,count_data,k8,candidate_cap32,d_total64,variant,encoding_mode,retention_mode,learn_tau,lambda_temporal. `ForecastModel` shared graph encoder/LIF/continuous controls, `.init_runtime(batch_size,device)`, `.monitor(observation,runtime)`, `.advance_clock`, `.refresh_graph(row_ids)`, `.update_states(node_ids)`, `.readout`, `.step`; `.forward(x,mask,age,raw,policy=None,event_priors=None,return_trace=False)` takes `[B,L,N,F]`, never targets. Returns predictions `[B,H,N,F]`, differentiable graph temporal loss and audit counters/traces. Normalizer raw mean/std and residual raw scale are model buffers or explicit frozen observation metadata. Separate runtime caches of graph support/weights/valid,membrane `[B,N,2,2,C]`,one pending-reset tensor,pending_log_g and graph/state/obs ages; previous predicted1 detached. Runtime resets per window.

Per-node row/state action indices represented as paired `(batch,node)` flattened IDs. Gather/cache updates remain differentiable in training (out-of-place functional scatter); inference may mutate isolated runtime. All-on reference equivalence has separate reference operation paths; all-off diagnostic bypasses forced initialization only when explicitly named. Actual scheduling initialization mandatory by default.

Candidate pool: seeded bounded exploration + visible contacts only, K≤4k clippedN−1; causal window-reset contact counters, same seed/exploration cadence for matched variants. No oracle/dense N×N scoring. Summary includes small recent-level/quality/age/residual statistics, stop-gradient monitor fields. Deterministic ID tie order. Confidence V9 fixes confidence-specific forward branch and temporal weight while raw observation/mask/age and candidate/exploration schedule stay the same. Local/neighbor encoder pathways separate until state readout.

## Engine owner interface

Config JSON/YAML using above exact semantics; CLI modules train/calibrate/evaluate/profile. Training logs every epoch/seed/checkpoint/config/source hashes; finite gradients and bounded states. Baselines persistence,linear,compactGRU first; V0/V1 full ANN before SNN campaign. AdamW and raw-unitmasked MSE, optional count-specific loss explicit and matched. Best required-horizon validationMAE; no test metric during tuning. Checkpoint includes model/config/buffers/selection evidence, never reusable runtime.

Calibration uses frozen params, val only, actual selective replay per candidate; max12 pilot policies/module. V5/V6/V7 checkpointV4,V8 checkpointV2. Validate active-scale cost tables rather than single-node linear extrapolation; graph/state nominal proportions distinguished from measured runtime budget. Mandatory init/age/audit, exceedance recorded. Evaluation weights hashed before/after and consumes full official custom test-window set; saves predictions and per-window errors/trace. Metrics horizon/feature/stratum and seeded paired-blockbootstrap separately. Profile same replay five times after10warmups, CPU/CUDA/device precision and actual model costs. Never reselect on final test.
