The full offline campaign includes eight clean deterministic simple-baseline
jobs and eight logical focal SNN intervention arms. The latter are four physical
V4 seed0 jobs, each producing a teacher and two intervention archives. They are
mandatory secondary evidence, not primary-family additions or five fictitious
repetitions of deterministic fits. Their absence prevents whole-test closure.

Preserve global completion helper v1 and all accepted source versions. Create
global_frozen_test_completion_v2.py with the same strict queue/completion and
acyclic prospective-path interfaces. Retain all five existing report contracts
and their checks unchanged. Add exactly these contracts:

* simple_v3: scope full_protocol, coverage n_windows, split test, phase evaluation,
  report evaluation_manifest.json, principal predictions.npz,
  metrics_by_horizon.csv and evaluation_manifest.json. The actual producer must
  declare method persistence or linear, seed_id0, oracle_accessed false,

* case_v2: scope frozen_case_signal_sensitivity_diagnostic, coverage origin_count,
  split test, phase evaluation, report case-signal-sensitivity-report.json.
  Principals are predictions-teacher.npz, predictions-relationship_removal.npz,
  predictions-focal_retention_removal.npz, all three corresponding
  metrics-<arm>-by-horizon-feature.csv files, case-signal-semantic-proof.jsonl,
  evaluation_manifest.json, the report and output-closure.json.
  The report binds variant V4/model_seed_id0, full policy, oracle_accessed false,
  targets_passed_to_kernel false and fixed directed nonself selected node IDs.
  All six archive/CSV output records are exact and hash-bound. Semantic proof
  counts equal origin_count*history and its path/hash is declared principal.
  Local verification actually checks ordered proof lines, graph/action hashes,
  complete origins, arrays and raw metrics; the global verifier does not decode
  NPZ/model/oracle payloads and must not claim those semantic checks itself.

Both actual original phase receipts expose outputs as a complete relative
filename->SHA256 map. They retain actual child UUID, byte-identical stable alias,
dispatcher before-snapshot, independent pretest refs and complete directory
membership/hash closure. Missing principal, extra/unhashed output, changed

refs -> prospective whole queue -> execution binding containing queue SHA ->
actual job/receipt -> root whole completion. A pre-existing authorization never
contains the future queue SHA when the queue itself hashes that authorization.
