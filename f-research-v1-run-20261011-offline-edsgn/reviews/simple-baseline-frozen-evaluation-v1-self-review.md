# Simple baseline frozen evaluation v1 — implementation self-review

This is a writer self-review of isolated staging code and CPU toy fixtures; it is not an independent review, root acceptance, or execution authorization. The evaluator has no fit routine. Before requesting a test loader it requires passed P2/P3/P3A with P4 running, the real owned two-lock/72-hour callback, P3 hash bindings for the train-fit manifest, linear coefficients, development acceptance and validation metrics, a separate root-accepted pretest authorization hash-bound in P3A, training-source and preprocessing/node-order digests, domain descriptor, exact output path, full current source hashes, and the official before-P4 validator. It rechecks the complete passed-stage references, data-file membership/hashes, authorization and source inputs immediately after the validator, before replay, and after serialization.

Replay reproduces `engine.simple_baselines`: persistence repeats the latest raw history value; linear uses the frozen coefficient on normalized history plus intercept; only count data clips predictions below zero. It preserves all legal ordered test origins, raw targets and masks, writes `predictions.npz`, per-horizon/feature raw metric rows, and a hash-checked manifest. The manifest distinguishes test-origin evaluation from test feedback and reports when a combined NPZ bundle was materialized.
