# Independent DCRNN training-prior review v1

**Disposition: numerical and artifact-integrity checks pass; root can accept these prior matrices for binding review.** This is not an experiment result, fairness decision, or DCRNN forecast evaluation. Independent recomputation details and hashes are in [the JSON log](../logs/dcrnn-training-prior-independent-v1.json). The matrix recomputation took 6.70 seconds wall time in the local Conda environment.

- **Email:** Independently counted directed training-bin event rows at `A[src,dst]`, preserving duplicates and excluding self edges. Exact match at `986×986`, train bounds `[0,562)`, 329,910 train event rows. The compressed NPZ materializes all 332,279 event rows, but only in-range train rows contribute; no out-of-train statistics were computed.
- **Email episode:** Same independent row-count reconstruction. Exact match at `893×893`, train bounds `[0,368)`, 220,126 train rows from 324,055 physically materialized event rows. This remains a same-source temporal supplement, not an independent dataset replication.
- **MOOC:** Built a binary CSR user-by-activity incidence matrix from distinct train `(user, activity)` pairs, then independently computed `B.T @ B` and zeroed the diagonal. Exact symmetric matrix match at `78×78`, train bounds `[0,499)`, 265,943 train event rows. User tokens were grouping keys, not graph nodes; repeated clicks by one user on an activity did not increase that user's incidence weight.
- **Synthetic:** Recomputed each ordered pair with `scipy.stats.pearsonr`, using `input_mask` at both lag endpoints and only the eight train trajectories, each separately bounded `[0,2048)`. No pair crossed a trajectory boundary. All 4,096 ordered pairs had 16,376 valid lag observations; none were low-sample or constant in these data. Matrix maximum absolute error was 0.0 (required tolerance `1e-6`). Separate hand checks confirmed that fewer than two observations or a constant side yields zero, while a varying identity pair yields correlation 1.

For every bundle, source-file hash, node ordering and digest, prior-array digest, finite values, zero diagonal, and the train-only flags in the manifest passed. The synthetic source hashes, train partitions, and split bounds also match. Reads were limited to real-bundle metadata/node IDs/events and synthetic train-file metadata/node IDs/values/input masks. The full compressed real event arrays were materialized as noted above; no target arrays, model, optimizer, GPU, validation/test measurements, or oracle files were opened.

The recipe remains a **full-training-period static prior**. Its later validation/test use is not origin-local, unlike EDSGN's window-local event replay; this is the asymmetric information-access caveat already disclosed in the proposal and must remain in baseline interpretation. The artifacts' graph values are compatible with the accepted recipe, but DCRNN supports must be constructed using v3's paired COO coordinate/value path because the v1/v2 upstream sparse helper misassigned values on the asymmetric toy graph. The priors themselves did not change.
