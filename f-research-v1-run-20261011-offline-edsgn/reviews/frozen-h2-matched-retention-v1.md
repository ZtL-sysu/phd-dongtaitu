# Frozen H2 matched-retention replay v1 — staging review

Status: **CPU toy prototype only; not integrated and not authorized for real data/checkpoint replay.** The driver uses the accepted `h2_matched_graph_retention_v2.py` intervention kernel and an explicit full-origin collection path. Public CLI pins its root to this run directory; `_root` and service injection are private toy-fixture hooks.

The path requires canonical `pipeline-state.json` P2/P3/P3A=`passed` with `gate_verdict=pass`, P4=`running`, and rechecks every P3A evidence/input file hash. Before replay it rejects either managed resource lock, owned model/resource processes, incomplete aggregate-budget coverage, and an exhausted 72-hour cumulative budget. It holds both locks, refreshes a whole-phase receipt and budget at each origin, and removes only its own locks on exit. The phase receipt records elapsed whole-process wall time including failure.

For test replay, a sibling immutable `test-freeze.json` must match checkpoint and parameter hashes, full dataset fingerprint, byte-level collection digest, exact source/dependency manifests, this driver and kernel hashes, all four intervention arms, `g=.9` / `log(g)=-80`, and full policy. Existing `engine.validate_freeze` is also called. Validation uses canonical P3A/P4 gates and the same frozen inputs. Source, dependency, data, normalization-helper, and checkpoint hashes are checked again after all origins.

The replay is B=1, FP32, eval/no-grad, with the model left in eval mode. At each legal ordered origin, only `x`, `mask`, `age`, `raw`, and optional event priors are passed to the kernel; `batch_at` targets remain outside it for scoring. It requires exact complete origin order, checks informative-arm parity, fixed parameters, full history graph-action proof hashes, and stores one prediction NPZ per teacher/arm with targets, masks, full origins, model seed, and trajectory seed. Predictions and targets are staged in memory-mapped arrays; graph action proof is JSONL with per-step hashes and candidate scorer/counter disclosure. Candidate scorer work and added teacher/arm replay time are labeled diagnostic overhead, with no speed or energy claim. Outputs are exclusive and existing output directories are rejected.

No real validation/test arrays or checkpoints were opened, no GPU or optimizer was used, and this prototype establishes no scientific result or gate passage.
