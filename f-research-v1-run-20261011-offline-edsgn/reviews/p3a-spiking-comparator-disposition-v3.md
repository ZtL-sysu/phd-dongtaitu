## SpikeSTAG

The primary arXiv record and full text are public: [arXiv:2508.02069](https://arxiv.org/abs/2508.02069), v2 (2025-08-18), and [full text](https://arxiv.org/html/2508.02069). This is forecasting, not classification: its problem definition maps a multivariate historical series to future values. It is the closest mechanism-family risk in this pair: adaptive learned graph, OBS graph attention, multi-scale sampled spiking GraphSAGE aggregation, followed by LSTM plus spiking self-attention fusion and a forecasting head. The paper specifies adaptive adjacency and main MSSA/DSF equations, but the public full text did not expose an author code URL. A bounded exact-title GitHub search did not verify an author repository; that is **not** evidence that no repository exists. No commit or code license can therefore be recorded. The arXiv record's non-exclusive paper-distribution license is not a code license.

Faithful paper translation is a possible research route, but is not established by this acquisition check. Before it could be called paper-faithful, an implementation audit would need to resolve paper-described local/semi-global sampling, OBS neighborhood attention, spiking aggregation time alignment and DSF/SSA details against the equations/figures, and identify any underspecified choices. The paper uses minute-of-hour/hour-of-day/day-of-week covariates; the local task has no agreed equivalent covariate feed. Silently zeroing or inventing those inputs would change the method. Any adaptation must state that input change and preserve the graph/SNN/fusion structure; it must never be labeled an official implementation without verified author source.

## SpikySpace

The primary record/full text are public: [arXiv:2601.02411](https://arxiv.org/abs/2601.02411), v2 (2026-02-10), and [full text](https://arxiv.org/html/2601.02411). The paper explicitly links the public anonymous archive [4open SpikySpace](https://anonymous.4open.science/r/SpikySpace). That URL resolved to an “Anonymous Github” page, but the bounded web reader returned no file listing; the public `/contents` route was inaccessible to the reader. No authentication or bypass was attempted. Consequently there is no verified source tree, commit, dependency list, or code license. The paper's CC BY 4.0 statement covers the paper, not automatically its code.

This is also a real multivariate forecasting paper, with historical sequence input and direct forecast horizons (the paper evaluates 3/6/12/24). Its core is a spiking state-space forecaster rather than a graph forecaster: Avg-IF spike encoding, selective SSM scan, PTSoftplus/PTSiLU, quantized projections and a forecast head. It trains a quantized ANN and converts it to an SNN, so directly training a conventional surrogate-gradient replacement would not be faithful. The published equations and appendices make a paper-derived implementation plausible, but its execution/training/quantization recipe and data-to-task adaptations would need a focused fidelity audit; it is not yet an executable author-code comparator. If that route is selected, label it `SpikySpace-paper-derived`, preserve ANN-to-SNN conversion and reported quantization/spike operations, and disclose the count-output/history/horizon adaptation. Do not import the paper's hardware-energy claim as local software evidence.
