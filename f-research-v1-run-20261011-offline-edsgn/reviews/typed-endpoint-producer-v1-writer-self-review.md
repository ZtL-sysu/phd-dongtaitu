# Typed endpoint producer v1: writer self-review

This is a staging engineering prototype, not an independent review, accepted analysis plan, P3A gate, scientific result, or claim decision. Public `produce_endpoint` requires the canonical RUN and official v4 metadata validator; injected roots/validators and `official=False` are rejected. It validates metadata and postrun manifest first, then rechecks semantic phase/dispatch receipts, return codes, immutable pretest bindings, freeze/checkpoint/parameter hashes, full-origin counts, driver format and H2 informative-teacher parity before opening prediction/trace/timing artifacts. It revalidates the canonical predecessor and consumed hashes before and after exclusive output serialization.

The numerical paths use the v4 sufficient-stat converters and existing forecast/scalar bootstrap kernels: required-horizon forecast pooling, streamed gzip graph rows for noise/response slices, and strict CSV parsing plus five-repeat median-of-five profile timings. Each output member distinguishes an identifiable result from a scientifically unidentifiable null-p result; unidentifiable epsilon is never replaced by a borrowed margin. Raw p, direction interval/effect and resampling receipt stay per endpoint. The producer emits no family adjustment or scientific claim status.

Five CPU toy tests passed: forecast horizon pooling/five-seed bootstrap, null-p unidentifiable NI, streamed graph trace/node-hash adapter, strict CSV type parsing, and separated cost-side CSVs with per-origin five-repeat medians. No test called the public official producer on a real P3A/P4 plan; no formal test arrays, model/checkpoint, GPU, optimizer, or phase were used. In particular, full accepted-manifest semantic integration for all four driver families remains pending root review and should be exercised only after canonical P3A/P4 authority.

Known implementation boundary: the cost path expects each seed's `driver_report` artifact to be the guarded profile v4 `runtime_summary.json`; H2 prediction archives must already be exported at the plan's bound `archive` paths, with matching targets/masks/origins. Graph trace paths must be the compressed v7 outer-step JSONL artifact and node order must hash to the accepted domain descriptor. Any schema mismatch fails closed. The H1 response uses the prepared switch map only after all phase outputs are proven complete; it does not read oracle files.
