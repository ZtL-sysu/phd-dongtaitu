# Independent review: split-history time-block robustness v1

Scope: read-only review of `edsgn/staging/split_history_robustness_v1.py`, its six CPU toy tests, the prototype note, and `protocols/c06-time-block-placement-repair-v1.md`. No prepared datasets, test values, models, GPU, or training were accessed. Local `dyg-cold` CPU pytest result: **6 passed** with explicit `PYTHONPATH` containing `edsgn/src` and `edsgn/staging`.

## Blockers / corrections before acceptance

**Major — the required realized window-history missing fraction is not emitted.** C06 requires both the requested within-union rate and the realized *weighted window-history* missing fraction (`c06-time-block-placement-repair-v1.md:21-26`). The freeze metadata stores only `realized_history_union_rate = block_len / union_len` (`split_history_robustness_v1.py:79-97,161-178`); this is not the replay-weighted fraction because bins in the interior of the union appear in more origin histories than edge bins. `perturbation_summary.effective_missing_fraction` is instead computed over the whole trajectory's observed input positions (`:128-132`). Add the deterministic fraction `sum_over_origins(hidden observed positions in [origin-L+1,origin]) / sum_over_origins(observed positions in that history)` (plus the all-time-bin equivalent if desired), and freeze it. This depends only on masks and origins, not targets or outcomes.

**Major — delegated summary fields become stale after applying the new block.** The wrapper first constructs `RobustnessPreparedData` with time-block rate zero so noise/jitter arrays are initialized, then replaces `_input_mask`, `_values`, `_obs_age` (`:111-130`). It updates missing fraction, hidden count and mask SHA, but leaves inherited `clean_true_zero_observed_positions`, `noisy_input_zero_positions_observed`, and `count_noise_applied_positions` unchanged. A CPU synthetic toy with 48×3 all-zero counts, 50% block, and count noise produced 114 actually visible positions but summary reported 144 for clean-zero and noise-applied positions. Recompute every “observed” summary field after the final split mask is installed, or label raw-noise-generation counts separately from model-visible counts. The actual window values/raw/masks are correctly zero-filled for hidden positions; this finding concerns provenance/QC counters.

**Major — freeze hash does not guarantee it hashes the executing wrapper.** `split_history_freeze_extras` hashes a caller-supplied `wrapper_path` (`:149-166`) but never requires it to equal `Path(__file__).resolve()`. A caller can freeze an unrelated in-root file and later pass that same file to validation while the actual wrapper changes. The toy tests currently do exactly this with a temporary `wrapper.py`, so they validate digest comparison but not implementation identity. Fail closed unless the frozen path resolves to the executing wrapper, or bind an explicit executing-module SHA internally and assert it at creation and validation.

**Major — the transitive perturbation implementation is not frozen here.** The wrapper delegates canonicalization, stable seed generation, noise/jitter construction, input normalization, event window logic, target delegation, and age calculation to `edsgn.robustness` (`:18-20,111-124,135-148`). Freeze metadata binds the split wrapper SHA but not `robustness.py`'s implementation SHA. A change to that dependency can alter realized behavior while this split-history freeze still validates. Add its exact SHA (or require and validate the existing robustness implementation digest in the same immutable extra).

**Moderate — domain-manifest binding is byte-strict but not semantically checked.** The helper checks that a caller-selected in-root path exists and freezes its SHA (`:149-166`); it never parses a schema or confirms the manifest's dataset identity, declared split/rate/domain, or source binding matches `data`. Later byte changes fail closed, but a wrong/arbitrary manifest can be frozen successfully. Before actual replay, specify a required manifest schema and cross-check its source/dataset identity and allowed split against the supplied prepared data and placement metadata. The current tests use a dummy `{"dataset":"toy-domain-v1"}` manifest and test tampering, not a coherent-but-wrong manifest.

## Verified behavior

- Split placement uses `data.origins(split)`, `history`, and `values.shape[0]` only (`:46-66`); it checks nonempty contiguous origins and the half-open union bounds. It does not inspect targets, target masks/values, test outcomes, or actual feature values to choose a block. The block is uniform over legal starts in the union, with stable seed from recipe seed, enumerated trajectory index, and source seed (`:68-97`). Rate zero draws no block.
- Same split/trajectory/source seed/recipe yields the same mask independent of method or model seed; no model seed enters `_time_block_bounds`. Bundle metadata records each enumeration index and source seed (`:194-219`). The toy checks deterministic same-index masks and different-index placement.
- The final input mask is original mask AND block visibility; normalized values are zeroed there and age is recomputed from the final mask (`:121-124`). Count-noise values and jitter offsets are initialized once through the existing wrapper with time-block disabled; event arrays/offsets are not overwritten by the wrapper. `target()` delegates to clean base data (`robustness.py:288-289`); toy tests compare target values and masks exactly.
- `random` and `related_group` route to the unchanged accepted wrapper (`:135-148`). Existing random/group/noise/jitter behavior is preserved at the array level by toy comparison. Event jitter remains causally windowed by the inherited wrapper, which filters future true events before offsets are applied (`robustness.py:254-276`).
- Empty/unsupported split and noncontiguous/out-of-range history ranges fail; missing wrapper/domain files, missing freeze fields, tampered wrapper/domain/recipe/origin metadata, and truncated trajectory bundles are covered by tests. Bundle equality binds per-trajectory ranges and count. One small hardening gap: `trajectory_index` accepts negative values and `int()` silently truncates nonintegral metadata; require a nonnegative integer before seed derivation.
- Input mask SHA is recorded in runtime `perturbation_summary`, but that SHA is not included in freeze metadata (`:128-130,161-178`). In a complete P4 integration the existing dataset fingerprint should bind source bundles; retain that independent binding and consider freezing the computed trajectory-mask SHA as a consistency check.
