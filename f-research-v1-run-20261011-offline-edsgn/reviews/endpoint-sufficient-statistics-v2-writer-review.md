# Endpoint sufficient-statistics v2 — writer self-review

This is a pure-array CPU converter, not a gated artifact producer, claim test, or statistical result. V1 remains unchanged. Forecast sums/counts retain required-horizon indexing and support exact full-post-switch [s,last authorized origin] selection. Heterogeneous cell masks are pooled from raw absolute-error sums and valid counts.

The graph converter consumes the actual frozen graph diagnostic outer step-record schema (`dataset_index`, `origin`, `history_step`, and a `graph_rows` list). A caller supplies five separate ordered streams keyed by model seed because the serialized step row itself does not carry model seed. It validates full origin/step order, per-step complete node coverage, initialized-before flags, row IDs and TV values while retaining only per-origin sufficient statistics and current-step rows. It rejects flattened v1 rows. `full_post_switch` covers every authorized origin at or after the prepared switch; fixed four-history pre/post/response slices remain available.

Switch mapping and trace IDs use strict integer validation; horizons and node IDs are positive/unique where applicable. Timing creates its pair lookup once and canonicalizes CPU/CUDA device labels. Tests include a tiny CPU `ForecastModel` forward captured by the v7 `TraceCapture`, converted from those actual captured outer records, plus synthetic streaming-order, gap, duplicate, slice, mask-pooling, and device fixtures. Local `dyg-cold` tests: 7 passed. No actual dataset, archive, checkpoint, GPU, training, or statistical endpoint was executed. Caller provenance/gate/freeze checks remain required before future producer use.
